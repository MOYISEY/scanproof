# ScanProof

Локальная подготовка фотографий письменной работы перед отправкой: порядок страниц, ручной чеклист заданий, предупреждения и один PDF.

## Что можно сделать

- Импортировать несколько JPG/JPEG, PNG или статических WebP с настоящими миниатюрами.
- Проверить снимки в крупном просмотре, переставить и повернуть страницы.
- Удалить страницы и восстановить их вместе с привязками.
- Ввести ожидаемые задания и вручную отметить, на каких страницах они находятся.
- Исправить название задания кнопкой-карандашом, сохранив его ID и все привязки. Enter/«Сохранить» применяет изменение, Escape/«Отмена» отменяет ввод. Пустое, слишком длинное или совпадающее с другим заданием название отклоняется без слияния связей.
- Увидеть непривязанные задания, точные байтовые дубликаты и подозрительно пустые листы.
- Подтвердить собственную проверку и скачать PDF в выбранном порядке.

Встроенный пример полностью синтетический. Данные пользователя в репозитории отсутствуют. Приложение не отправляет фотографии на сервер, не использует аккаунты, аналитику, платные API или внешние зависимости.

## Запуск локально

Нужны Node.js 22+ и современный браузер с Canvas, Web Crypto, IndexedDB и Web Locks. Установка npm-пакетов не требуется.

```sh
git clone https://github.com/MOYISEY/scanproof.git
cd scanproof
npm run dev
```

Откройте `http://127.0.0.1:4173`. Сервер слушает только loopback и не принимает загрузки файлов.

```sh
npm test
npm run build
node scripts/serve.mjs --dist
```

`dist/` содержит только статическое приложение. CI проверяет логику и сборку, затем публикует этот каталог в GitHub Pages. Официальные Actions закреплены на точных commit SHA. Никакие секреты для сборки не требуются.

## Лимиты и честные границы

20 активных страниц, 10 МиБ на файл, 50 МиБ оригиналов суммарно, 24 мегапикселя на фотографию. До 100 заданий, по 160 символов в названии. HEIC/HEIF, PDF, SVG, GIF, APNG и анимированный WebP отклоняются. Ошибка одного файла или отмена импорта не добавляет часть набора и не меняет текущую работу.

Пустота — **эвристика по пикселям**, которая может ошибаться на бледных или тёмных снимках. Дубликат — совпадение SHA-256 исходных байтов; похожие фотографии не распознаются. Карта заданий показывает ручные привязки, а не правильность или полноту ответов.

**Нет OCR, AI, распознавания формул, автоматической оценки читаемости, коррекции перспективы или отправки в LMS.** Порядок, читаемость и полноту проверяет человек. Проект не заявляет уникальность или подтверждённый спрос.

PDF: A4 по итоговой ориентации, белые поля, RGB/JPEG 94%, длинная сторона до 3200 px. Маленькие снимки не увеличиваются в пикселях. Исходники не меняются. Нет текстового слоя, PDF/A, карты заданий, электронной подписи или гарантии лимитов конкретной учебной системы. Откройте скачанный файл перед отправкой.

## Черновик и приватность

Черновик автоматически хранится в IndexedDB браузера: оригиналы, порядок, повороты, привязки и последняя выбранная для просмотра страница. Смена страницы сама по себе не меняет работу, не отменяет ручное подтверждение и не убирает уже готовую ссылку PDF в открытой вкладке. **После перезагрузки страницы подтверждение проверки ставится заново, PDF создаётся заново.** Вторая вкладка блокируется через Web Locks, чтобы не перезаписать работу. Повреждённая запись сохраняется без автоперезаписи; её можно явно удалить. При ошибке сохранения текущая работа остаётся в памяти, а статус сообщает об ошибке.

Это не резервная копия и не шифрованное хранилище. Очистка данных сайта, приватный режим, нехватка места или политика браузера могут удалить данные. История восстановления удалённых страниц существует только до следующего успешного импорта или перезагрузки.

Хранилище привязано к origin — протоколу, домену и порту. Проекты одного домена GitHub Pages используют общий origin: другое приложение этого домена потенциально может читать локальные данные. Для изоляции можно запустить локальную версию. Данные доступны также другим пользователям того же браузерного профиля. Регулярно скачивайте PDF; кнопка удаления черновика внизу очищает текущую работу и сохранённую запись с подтверждением.

PWA и гарантированный запуск без сети не заявлены. После загрузки обработка выполняется локально. Проверено в Chromium на desktop и мобильной эмуляции; физические телефоны, Safari, Firefox и скринридеры отдельно не проверялись.

## Проверки

`npm test` запускает 14 проверок: типы и лимиты файлов, эвристика пустоты, устойчивые привязки при перестановке/delete/undo, дубликаты, ввод и переименование заданий, структура PDF, валидация черновика и чистая воспроизводимая сборка. Проект также прошёл браузерные сценарии с синтетическими JPG/PNG/WebP, клавиатурой, мобильной эмуляцией, rename/cancel/reload, сохранением просмотра и независимым открытием экспортированного PDF.
